# EMTAF v1.9 Role-Based Staff Training Package

This package contains role-specific training decks for the EMTAF multi-tenant platform.

## Modules
- All Staff
- Hospital Receptionist
- Hospital Doctor
- Hospital Nurse
- Hospital Accountant
- Hospital Administrator
- Hospital Superadmin
- School Staff
- College Staff
- Hotel Staff
- Real Estate Staff
- Platform Administration / DevOps

## Recommended sequence
All Staff -> Role Module -> Hands-on Sandbox -> Scenario Exercise -> Knowledge Check -> Sign-off.

Use only sample/non-production data for training.
